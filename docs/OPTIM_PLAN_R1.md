## 1．計畫清單（逐項可驗收）

### A．開場 60 秒抓住玩家（好玩）

- [x] A1 標題畫面重做：標題時隱藏遊戲 HUD；改成半透明漸層讓街景透出，加入「斷鏈」圖形標誌、標語與一句故事鉤子；主按鈕「開始行動」放第一顆且視覺最強。驗收：標題截圖中 HUD 不可見；主按鈕 ≥56 px 高並排第一。
- [x] A2 開場故事卡（約 15 秒、可點擊推進、可跳過）：以虛構「恆曜投資教育」群組訊息交代阿遠被騙經過，最後一張把玩家交給美晴。只在標題「開始行動」觸發，重開與測試直接進遊戲。驗收：新測試確認故事卡可逐張推進、可跳過、結束後解除暫停並顯示 MAIN-001 標題橫幅。
- [x] A3 3D 目標信標：當前任務目標位置顯示光柱＋地面脈衝圈＋浮動箭頭，任務卡顯示目標距離（公尺）。驗收：新測試確認信標跟隨 `missions.get_target_key()` 位置、到達時淡出；截圖可見。
- [x] A4 任務開場橫幅＋角色台詞字幕：每個主線任務開始顯示大標題與 `dialogue` 台詞（說話者名字上色）。驗收：新測試確認任務切換時橫幅文字等於任務標題、字幕含 dialogue。
- [x] A5 目標完成回饋：每完成一個目標顯示「✓ 目標完成」提示＋確認音；任務完成顯示零件券獎勵。驗收：新測試確認目標索引前進時觸發提示。

### B．核心循環與打擊感（好玩＋美觀）

- [x] B1 命中回饋組：動畫停頓（只停骨架動畫 70 ms，不改 `Engine.time_scale`、不改判定窗）、鏡頭震動、命中火花粒子、浮動傷害數字、命中音隨機音高、敵人／物件受擊白閃。驗收：新測試確認命中觸發 `hit_landed` 訊號、產生火花與數字節點、停頓後動畫速度恢復；`release_regressions` 判定窗測試不變仍綠。
- [x] B2 連擊計數：1.6 秒內連續命中顯示「連擊 ×N」。驗收：新測試確認連擊數累加與逾時歸零。
- [x] B3 揮擊音：揮空也有破風聲（新增合成音），讓揮空與命中可分辨。

### C．讓人想再玩一局（好玩）

- [x] C1 章節結算評價：依用時、證據、街坊信任、救出人數、警戒計算 S／A／B／C；三種解法（破壞／蒐證／救援）各自記錄最佳評價，存在獨立的 `user://seven-district-records-v1.cfg`（不進存檔、測試不落盤）。結算畫面顯示「解法完成 1／3」與下一個建議解法。驗收：新測試確認評分函式邊界、紀錄只升不降、三解法進度文字。

### D．招牌玩法與在地故事（反同質化）

- [x] D1「斷鏈」進度：HUD 任務卡顯示五節鎖鏈，每完成一個主線任務斷一節，斷鏈時有動畫與音效；呼應片名與「追討被騙存款」主題。驗收：新測試確認斷鏈數＝已完成主線數。
- [x] D2 開場故事卡（A2）、任務台詞（A4）讓台中外送員被假投資詐騙的故事在前 60 秒被看見。

### E．美觀：光影、色調、介面

- [x] E1 光影：環境光改用天空來源並提高能量、調整暖色日照與霧色、開啟輕度 glow 與色彩調整（飽和 1.12、對比 1.05）。不改日照能量公式（既有測試鎖定）。驗收：after 桌機起始畫面平均飽和 ≥ before＋0.03，低飽和像素比例下降。
- [x] E2 角色可讀性：主角、安保、受困者材質加邊緣光（rim）並提高環境光，主角裁切近黑像素降到 30% 以下。驗收：同一裁切框重新量測。
- [x] E3 地面：核心區 300×300 地面與車店前廣場改為帶細微雜訊紋理的鋪面材質，消除平塗灰。驗收：截圖對照。
- [x] E4 HUD 重排：任務卡縮成左上窄卡（桌機寬 ≤ 480 px），加入安全值條與體力條；分數列移到暫停／手機；底部提示改成置中膠囊；操作說明 45 秒後收起。驗收：桌機 HUD 遮擋面積由約 42% 降到 ≤ 20%（以控制項矩形計算，新測試輸出）。
- [x] E5 觸控介面：指令鈕移出畫面中央（直式在頂端一列、橫式在右上 3×2），按鈕改圓角半透明樣式、攻擊鈕強調色；直式提示面板不再蓋住「連跑」。驗收：新測試在 390×844、844×390 檢查指令鈕不與任務卡、提示面板、連跑鈕重疊，且全部 ≥44 px；既有 `device_profiles` 安全區與 44 px 測試仍綠。

### F．聲音

- [x] F1 配樂：用本機 AI 派工器（ACE-Step）生成標題曲與街區循環曲各 30 秒，標題／遊戲切換、選單時壓低音量、尊重靜音。來源寫入 CREDITS。若派工失敗，列缺件並保留可替換架構（`music_director.gd` 讀固定路徑，缺檔靜默）。
- [x] F2 新合成音：破風、目標完成、任務完成、斷鏈、介面確認，由 `tools/make_audio.py` 重現生成。
