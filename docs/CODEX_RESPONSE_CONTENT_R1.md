工作單日期 2026-10-18；驗證收尾 2026-10-19，main，版本 **0.15.0**。三項內容、完整 Godot 無頭回歸與 Web 多視口實證均為 VERIFIED；效能出貨閘為 BLOCKED。

## 三宗案件與入口

共同入口是「暫停 → 查證 → 街坊查證簿」。不需要完成主線、登入或等待某一天。選案後先讀待訪來源，返回街區跟隨目標導引；必須下車並靠近三公尺內互動，選單不能直接領取證物。按「暫放導引」可恢復原任務，已留存的文件不會遺失。

| 內容 | 實際完成內容與玩法 | 完成回饋 |
|---|---|---|
| 第二次求助，第二次收費 | 在美晴車店與留證桌取得虛構「澄岸協助所」同一案號的兩份文件。比對「不收預付費」與「先付代辦費」，選出真正前後矛盾的承諾。案件名稱、文件、位置、題目、選項、正解、重試提示及結論都由 `godot/data/fraud_cases.json` 提供，可換資料而不用改這宗案件的介面。 | 朱紅「已封存」及有界結論：說詞矛盾不能證明任何人身分，也不能保證追回款項。 |
| 晚班之前的收據 | 車店收據 17：42、留言摘要台交接摘要 17：55、側門晚班單 18：00，逐張點選排先後。可撤回最後一張，配錯不扣分。既有「章節回訪」第二份也有「新查證」入口，不取代原回訪或後記。 | 排出的時間線推翻「收據一定來自晚班」的第一印象；不能進一步指認經手人，或推定白班有人涉案。 |
| 三張嘴，一句真話 | 到晨光市場找林秀蘭、便利店找陳奕廷、橘盒站找吳安琪，取得同一七號收件簿的互斥說法與三份原件。逐句選證物，再判斷「支持／推翻」；可換句、重配，保留先前正確核對。 | 三句均核對後封存：末筆推翻「全在六點前」、首筆推翻「全在六點後」、索引支持「前後都有」。記憶不合不能當作故意說謊或犯罪證明。 |

人物、機構、案號、地點與文件均為虛構。新文案只描述如何辨認證據矛盾，沒有付款連結、可照做的施詐流程或真實帳號。三項都是離線內容，沒有廣告、內購、外部連結、第三方 SDK、帳號、線上服務或每日打卡。

新測試涵蓋：遠端／騎乘取證拒絕、真正世界的來源位置互動、逐件自動存檔、五種錯誤時間全排列、撤回與重排、全部錯誤人證配對、完整索引的額外有效反證及其存檔、每宗案的實際按鈕完成、完成存檔、JSON／磁碟讀回、壞資料保留目前狀態及舊世界存檔相容。另逐頁檢查九種視口的待訪、每張證物、推論與封存，觸控目標至少 44px，正文與返回不越界。無頭場景測試將測試角色放到真實來源位置再呼叫遊戲互動；不冒稱以按鍵走完所有長距離路線。

每次取證、放入／撤回時間證物及正確配對，都接入既有原子存檔；完成不另給可重複刷取的貨幣。人證最後一組配對與封存使用同一次有效更新，避免先存下「三組都核對、卻未封存」的不完整中間狀態；新測試逐次驗證每個自動存檔訊號的合法性。案卷為獨立分頁，原案卷、五主線、回訪、街坊生活及角色骨架流程保留。
