## 八大面向與品質閘

1. 美術：製作本作專用案卷介面，沿用合法既有模型，不新增點陣插畫。新 2D 若無可確認 gpt-image-2 slug 不生成，列缺件；不以程序方塊冒充美術。
2. 按鈕：新案卷控制至少 44px、無重疊，固定返回；多長寬比測試。
3. 選單：案卷採單頁分步，每步有返回；前一頁與主線均可回到。
4. 人物：用美晴的核對對話深化角色，沿用既有臉部與骨架，不冒稱新角色製作。
5. 地圖模型：沿用街區與車店，驗證實際站點靠近與地面；不新增佔位場景。
6. 技能：核心為證據核對；錯選有理由、正確才封存，不消耗道具，既有戰鬥回歸保留。
7. 角色樣子：本輪不重做材質／三視圖雙閘，不冒用舊驗證當新完成。
8. 動作：不新增戰鬥動畫，保持骨架／命中窗既有測試；原生觸控補驗真物理移動與背景恢復。

效能一律標「並發載量測，僅供參考」；此機況不能證明 p95 ≤18ms。iOS／Android 實機、TestFlight beta 回饋、簽章成品隱私與離線、完整原生長時測試列 BLOCKED，不能宣稱通過商店審查。
