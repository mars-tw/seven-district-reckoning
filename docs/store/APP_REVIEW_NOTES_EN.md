# App Review Notes — prepared locally, not submitted

Source version: 0.7.0. These instructions describe this local source revision. A new signed iOS build, device testing and beta feedback are still required. The previously rejected 1.0.0 binary does not automatically contain these changes.

Seven District is an original Traditional Chinese third-person story game about a fictional delivery worker investigating an investment scam in a fictional Taiwan neighbourhood. The opening now contains an interactive evidence file, not just a scam-themed introduction. There is no login, server dependency, advertising, tracking SDK or purchase in the game source.

To see the signature mechanic in approximately three minutes after loading:

1. Tap 開始行動 (Start). Read the four short story cards, or tap 跳過 at the top right. The fictional customer-service message is preserved in the case file even when the introduction is skipped.
2. Use the lower-left joystick to walk toward the nearby objective beacon at Mei's bicycle-shop desk, approximately six metres from the starting position. Drag on the right to look around. Tap the contextual 交談 (Talk) action when close to the desk. This completes the first campaign objective and opens the receipt comparison.
3. Select 受款帳戶是恆曜公司專戶 (the claim that the recipient is a company account). Then select 戶名：林○翔（個人） (the individual account-holder entry). Finally select 公司專戶的說詞與個人戶名矛盾 (the supported contradiction). Choosing an unsupported pair or conclusion explains the problem and allows another attempt.
4. The sealed file explains the limited inference: the account-name contradiction challenges the claim but does not establish who masterminded the fraud. Tap 回到街區，繼續斷鏈 to return. The file remains available from Pause → 反詐案卷. Pause → 進度 contains save/load controls. After relaunch, use 讀取存檔 on the title screen.

All messages, names and transaction details are fictional game content. No real banking, messaging or personal data is accessed. Case progress is stored with the campaign on the device. The current content is one opening case, the existing five-mission first chapter and three character-revisit routes; we do not claim a completed multi-chapter campaign.
