## 八大面向

| 面向 | 本輪做／不做與理由 |
|---|---|
| 1 美術 | 做 UI 可讀性與現有色票一致性；不新增 2D 插畫，內容以文字及既有素材呈現。沒有可確認 slug 的 `gpt-image-2` 來源，不以程序圖冒充新美術 |
| 2 按鈕 | 做 ≥44px、左右下拇指區、互動動詞、多指取消、四個視口矩形與遮擋驗證 |
| 3 選單 | 做暫停分頁、常駐返回、回訪卡分頁；既有大型資料選單仍可捲動，但返回鍵不隨內容消失 |
| 4 人物 | 不換人物／骨架；新內容用人物後記深化現有角色，避免無授權模型 |
| 5 地圖模型 | 不建新模型；回訪使用現有街區與地標、光柱導引，驗證站點物理可達 |
| 6 技能 | 不加戰鬥技能；做互動的確認、錯答與取消回饋，原傷害／消耗規則維持回歸 |
| 7 角色樣子 | 不改角色材質／外觀；沿用 R1 結果，不能把舊圖當本輪新三視圖通過 |
| 8 動作流暢度 | 不新增動畫；用實際玩家骨架移動驗證觸控，跑既有命中窗／揮空／受擊回歸 |
