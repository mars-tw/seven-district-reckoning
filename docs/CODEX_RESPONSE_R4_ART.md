# R4 美術重做回覆

日期：2026-10-16。版本：**0.8.0**。本輪為 **EXECUTED**；素材／來源與無頭版面測試分別驗證，**整體美術出貨驗收仍 BLOCKED**。只操作本 repo 的 main，只做本機 commit；沒有 push、部署、商店操作、可見視窗、瀏覽器、外部派工或秘密目錄存取。

**VERIFIED：Godot 4.7 工作來源與 Godot 4.7.2 待提交乾淨來源，各 23 組、13,308 項、零失敗。** 包含匯入／解析、既有玩法與 UI 回歸、修復後 native fixture、新美術資源與跨裝置版面；素材／字型／版本與秘密掃描另有讀回證據。

## 最大三項改變

1. **標題有自己的長相。** 新增台中黃昏車店插畫、粗黑斷裂 Logo 與斷鏈 App 圖示提案；移除標題的空框鏈條列，保留可讀中文標題與固定「開始行動」。主視覺明確是插畫，不是 3D 遊戲截圖。
2. **角色與證物實際進入介面。** 阿遠／美晴使用有臉的透明立繪；開場依說話段落切換，美晴的主線對話也有肖像。案卷接入手機／收據插畫、紙纖維面板、封存圖示及亮起回饋。金額、戶名與推論維持真實遊戲文字；取得收據之前不展示收據插畫。
3. **UI 與街景改用本作語彙。** 主要 HUD、選單與觸控按鈕採炭墨、證據黃、裝訂直邊及 2px 小圓角，移除藍綠膠囊。街道／騎樓／前院使用新材質，降低全天過強的環境填光、強化側光層次；沒有新建方塊模型，既有碰撞、真骨架與命中窗保持原契約。

## 素材品質與大小

- **VERIFIED**：四角 alpha=0、透明區 RGB 清零、半透明抗鋸齒保留；沒有假透明棋盤格。兩張立繪與四枚圖示均實際讀回確認。標題 Logo 有半透明印刷光暈，仍需最終畫面檢查。
- **VERIFIED**：兩張立繪以可見 alpha>127 像素計算 HSV V／S。阿遠：V 0.349、近黑 25.3%、S 0.478、低飽和 3.8%；美晴：V 0.487、近黑 6.3%、S 0.594、低飽和 2.2%。近黑定義 V<0.15，低飽和定義 S<0.15；均符合本輪雙閘。這不是 3D 模型三視圖驗收。
- **EXECUTED**：`docs/evidence/r4-art/portrait-64px.png` 為 64px 臉部／全身立繪縮圖；`app-icon-thumbnails.png` 為 48／64／128px 圖示。已自行查看，沒有假稱完成五人盲測。
- 新增遊戲用壓縮圖片共 **2,540,189 bytes（2.42 MiB）**，全部解碼為 RGBA 的理論上限約 **17.22 MiB**。無損母圖約 **16.67 MiB**，放在 `godot/` 外，不進遊戲匯出。歷史對照 PNG 與報告也不屬遊戲包體。尚未產生新原生安裝包，因此實際封包差額仍未量測。
- 後製為 LANCZOS 尺寸調整、角色飽和／亮度校正、alpha 清理、圖示切片、街景材質 20px 邊緣接縫混合。沒有拿程序色塊替代插畫；新材質不搭配無關的舊 normal／ORM 假裝完整 PBR。

## 測試與 native 阻塞

指定執行檔實際版本為 **Godot 4.7 stable**，不能寫成 4.7.2。正式完整指令：`python tools/test_game.py --godot <指定的 Godot console> --report-path docs/evidence/r4-art/final-tests.json`。完整結果以該 JSON 的逐 suite 紀錄為準；待提交來源的引擎／指紋與測試證據另列於 `staged-tests.json`。

改前完整回歸：21 組、12,018 項、零失敗。R4 新增美術／版面 1,278 項；native 原 fixture 修復後為 12 項。R4 版面涵蓋 320×568、390×844、844×390、768×1024、1024×768、1366×600、1280×640、1920×1080，以及商店截圖對應的 430×932、1032×1376。既有 R3 另保留 14 視口、八種案卷狀態的更嚴格操作斷言。測試證明尺寸、位置、無重疊、44px 目標、無須捲動才能選案卷與手機文案；**不代表像素視覺驗收**。

上一輪 `tests/native_touch.gd` 先原樣重現：兩影格後對空的 `device_profiles` 呼叫 `initialize`，18 秒逾時，原雜湊及錯誤見 `before-native_touch.json`。本輪改為有 30 秒上限的 `expansion_complete` 就緒條件，待 `_ready` 完成後才設測試模式；保留全部原斷言，增加就緒斷言，納入正式 runner。native 觸控 fixture 已修復；這不代表 iOS／Android 原生成品已驗收。

首次新 UI 測試曾抓出觸控按鈕內距及案卷縮高的問題，已修正程式後再測，沒有放寬斷言。中間失敗紀錄保留為修正證據。素材、字型、版本、既有工作保留及秘密掃描結果在 `docs/evidence/r4-art/`。
