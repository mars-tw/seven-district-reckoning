# Alpha 0.3 網頁單人版

[直接線上遊玩](https://seven-district-reckoning.digimkt.workers.dev)。這個版本可在瀏覽器執行 Godot 遊戲，免安裝；首次開啟需要下載遊戲資料。

Alpha 0.3 已上線。下列地圖、補給與設定操作可直接使用，既有 Alpha 0.1／0.2 存檔也可接續。

## 進入街區

1. 從 HTTPS 發布網址開啟遊戲，按「開始線上遊玩」。
2. 等待真正的遊戲下載與啟動進度完成，再按「進入街區」開始新遊戲。已有進度可按「讀取存檔」。
3. 依左上角主線目標找美晴、查看訊息與取得扳手。靠近角色、終端或物件時，畫面會顯示可用操作。

使用支援 JavaScript、WebAssembly 與 WebGL 2 的瀏覽器，並開啟硬體加速。遊戲啟動需要玩家點擊；音效、全螢幕與瀏覽器操作也可能需要這次手勢。若音效尚未播放，先點回遊戲畫面或遊戲選單。

## 鍵盤與滑鼠

網頁版滑鼠保持可見，**按住右鍵拖曳**即可轉動視角。原生桌面版維持捕捉滑鼠的操作。

| 操作 | 網頁版控制 |
| --- | --- |
| 步行；騎乘時加速與轉向 | WASD |
| 衝刺 | Shift |
| 轉動視角 | 按住滑鼠右鍵拖曳 |
| 攻擊 | 滑鼠左鍵 |
| 跳躍；騎乘時煞車 | Space |
| 交談、領取、交付或啟動目標 | E |
| 上下汽車或自行車 | F |
| 切換已取得的器具 | Q |
| 取回目前載具 | R |
| 任務手機 | Tab；網頁「任務與委託」可直接開啟可選內容 |
| 大地圖與導航 | M；或網頁「地圖」 |
| 街區挑戰與車店補給 | 網頁「補給與挑戰」；購買需靠近車店 |
| 畫質、難度、視角與音效 | 網頁或遊戲選單的「設定」 |
| 暫停／繼續 | 遊戲或網頁選單；Esc 也可能先離開全螢幕 |
| 存檔／讀檔 | 網頁操作列或遊戲暫停選單 |

請先點遊戲畫面，讓鍵盤焦點回到遊戲。瀏覽器可能把 F5 當成重新整理，也可能攔截 Tab 或 Esc；網頁按鈕可處理任務、地圖、補給、設定與存讀檔。全螢幕按鈕只放大遊戲區；瀏覽器缺少原生全螢幕功能，或拒絕請求時，會改為填滿分頁。按「返回頁面」或 Esc 可離開頁內放大。

載具速度太快或出口受阻時，先煞車再下車。可在暫停選單重試主線檢查點；已完成的支線成果與相簿紀錄會保留。

## 觸控操作

觸控裝置請用**橫向與全螢幕**。畫面內有方向、攻擊、互動、上下車、跳／煞、換工具與取回按鈕；「視角←／視角→」可轉動鏡頭，右半邊拖曳也可調整視角。「委託」開啟可選內容，「暫停」開啟遊戲選單。網頁的「觸控按鈕」可以切換操作區。

手機瀏覽器若沒有原生全螢幕，「全螢幕」仍可放大遊戲區，再按右上「返回頁面」縮回。網頁操作列的地圖、補給與設定會依寬度換行；進入遊戲後可使用這些按鈕。

操作區太小時，遊戲會隱藏按鈕並提示放大畫面。觸控介面與小尺寸選單已做場景檢查；各手機瀏覽器的多點觸控、畫面流暢度與長時間遊玩仍需實機測試。

## 地圖、補給與街區挑戰

按 M 或「地圖」查看目前位置與街區目的地。點選目的地只會設定導航標示，角色仍需步行、騎車或開車前往。

衝刺會消耗體力；停止衝刺後會恢復。體力預設上限為 100，購買體能訓練後提高到 120。補給金是存檔內的遊戲資源，和主線分數、支線零件券分開記錄。

在「補給與挑戰」查看進度。完成挑戰後自動領一次補給金與經驗；重複完成相同目標不會再領獎。

| 街區挑戰 | 計入條件 |
| --- | --- |
| 用雙腳認路 | 步行累積 400 公尺；搭車與重生位移不計。 |
| 三份交代 | 完成三份不同支線；重玩活動不計。 |
| 停用營運設備 | 用工具停用八個不同的合法設備或訓練道具；路人、證據與重複目標不計。 |

到美晴車店附近，再開「補給與挑戰」購買。不同補給有等級與次數限制；生命已滿時買急救補給不會扣款。

| 補給 | 費用與效果 |
| --- | --- |
| 急救補給 | 35 補給金，恢復最多 40 點生命。 |
| 體能訓練 | 90 補給金，體力上限提高到 120；需街區等級 2，只能買一次。 |
| 工具整備 | 140 補給金，工具傷害提高 20%；需街區等級 3，只能買一次。 |
| 自行車調校 | 105 補給金，自行車加速提高 15%；需街區等級 2，只能買一次。 |

## 畫質與操作設定

「設定」可調整省電／均衡／細緻三種畫質、標準／輕鬆難度、視角靈敏度、音效與日夜循環。細緻模式啟用陰影；手機若畫面變慢，可先選效能模式。輕鬆難度降低受到的傷害與守衛追逐壓力。

日夜循環開啟時，遊戲內的一天約為實際遊玩 20 分鐘。開啟選單會暫停世界；設定與街區進度會隨存檔保留。

## 六個委託與四個活動

從任務手機的街坊委託，或網頁「任務與委託」選擇可選內容。接單後依目前目標找標示物件；可選任務會顯示在遊戲內。

| 支線 | 做什麼 |
| --- | --- |
| 招牌不會自己倒 | 關掉三塊招攬看板，把廣告交回美晴。 |
| 沒寄出去的信 | 找回三封信，交給予安。 |
| 沒拿回來的背包 | 找回周成的背包，把水與衣物送到集合點。 |
| 美晴的零件單 | 騎自行車取回三處零件，再到維修檯裝上。 |
| 巷子裡的送達 | 領取餐盒，騎自行車送給兩位街坊。 |
| 把早餐店開回來 | 修好招牌、取回互助箱，整理安全屋角落。 |

| 活動 | 條件 |
| --- | --- |
| 自行車路標賽 | 騎自行車出發，90 秒內依序通過四個路標。 |
| 停車場繞標 | 開車出發，120 秒內依序通過三處路標，再把整台車對齊停入車格並煞停。 |
| 街景留影 | 到八個街景點按 E 收進相簿。 |
| 社區急送 | 領取包裹後，180 秒內送到三個收件點；順序自選，可步行或使用載具。 |

活動計時從出發事件開始，開啟手機或暫停時會停止計時。失敗後可重新接同一活動。活動首次完成領一次獎勵，重玩更新個人最佳；街景每個地點只領一次獎勵，相簿在取消與重接後仍保留。支線與活動有各自的成果與零件券紀錄。

這些內容位於現有 **300 × 300 m** Alpha 地圖內。舊街車店、商辦核心、公園步道、停車廣場、前站廣場與轉運街區是六個周邊街區；背景加入八位行人、四台行駛車與六台停放車。完整 800 × 800 m MVP 與其全部任務仍在規劃中。

Alpha 0.3 換上人體比例的角色，並加入商辦幕牆、店面、人行道、長椅與道路材質。地圖以七期商辦街廓為靈感，街道與建築皆為虛構，沒有匯入真實 GIS 圖資。

## 存檔留在哪裡

網頁版透過瀏覽器 **IndexedDB** 儲存進度。請用同一個瀏覽器、同一個網站網址回來讀檔。換瀏覽器、換網站來源或換裝置，無法讀到原來的資料；網頁與 Windows 存檔分開。

清除網站資料會刪除存檔。無痕模式、儲存空間不足或瀏覽器限制也可能讓資料無法保留。遊戲不提供帳號或跨裝置雲端同步，存檔前請使用遊戲的「存檔」操作。

## 載入不順

載入失敗時按「重新載入遊戲」，重新進入整個頁面。請檢查網路、WebGL 2 與硬體加速；若圖形連線中斷，可先關閉其他耗用圖形的分頁再重試。不要直接雙擊本機 HTML 檔案啟動網頁遊戲。

JavaScript 無法使用時，頁面會保留需求說明與 [Windows Alpha 0.1.0](https://github.com/mars-tw/seven-district-reckoning/releases/tag/v0.1.0)下載入口。這個下載是歷史桌面版本，沒有 Alpha 0.2／0.3 新增的街區、可選內容或新系統。
