# Alpha 0.1.0 驗證紀錄

本報告只涵蓋目前第一章 Alpha。原始50張工單、70項資產與完整六區MVP仍是後續製作範圍。

## 實際執行

| 檢查 | 結果與證據 |
| --- | --- |
| 官方工具 | Godot 4.7.2 stable、Blender 5.2.0 LTS；Godot editor及Windows export templates均核對官方SHA-512 |
| 匯入／解析 | Godot headless editor匯入GLB、字型、音效及腳本；未留下parse／script error |
| 整合流程 | 9項：五任務串接、事件去重、救援、JSON及世界存檔還原、玩家／自行車／汽車的實際物理移動與上下車 |
| 任務與介面 | 233項契約：三分支、分數、錯序／重複事件、重試、腐損備份、HUD尺寸與按鈕 |
| 控制 | 44項：真正命中時間窗、牆面遮擋、有限脈衝能量、跳躍、載具限速、煞車、安全出口、輪組與曲柄動畫 |
| 守衛持久化 | 16項：活／倒地狀態、碰撞、生命、座標、重複事件及不合法資料拒絕 |
| 獨立回歸 | 37項：E不能代替打砸、提前破壞保護、真正攻擊、讀檔後重試、救援提早抵達、破壞後合法存檔、載具占用與New Game |
| Blender | 25份源檔與25個GLB；二次匯入骨架／UV／bounds／clip一致；三角色各9骨及8個clips |
| 發布資料 | 對已進Git索引的候選檔掃描；文字秘密與私人路徑零命中；Blender及GLB另有metadata檢查 |

測試碼已放在tests/，可用tools/test_game.py重跑。玩家使用slot1；測試僅使用保留的95～98 fixture槽。流程事件檢查與實際控制檢查分開記錄，沒有把程式派送任務事件稱作人類全程試玩。

## 短場景效能

參考裝置為NVIDIA GeForce RTX 2060，OpenGL3.3 Compatibility，1366×768。固定場景，2秒暖機後量測12秒，連續三跑。以單調時鐘的process callback間隔計算，未使用經平滑的遊戲delta。

| 次數 | 幀數 | p95 | p99 |
| --- | ---: | ---: | ---: |
| 1 | 719 | 17.200ms | 18.701ms |
| 2 | 719 | 17.206ms | 18.418ms |
| 3 | 719 | 17.007ms | 18.813ms |

三跑p95中位數17.200ms。這是目前Alpha的短場景量測，含2名守衛、4名受困者；不能代表完整MVP的16敵／24行人／12車壓力、手機、長時間穩定性或最低配備。Memory欄位是Godot的內部static allocation監測，不等於完整作業系統process RSS。[原始資料1](../qa/profile-run-1.json)／[2](../qa/profile-run-2.json)／[3](../qa/profile-run-3.json)

## 修正與尚待驗收

獨立覆核發現並修正：E跳過打砸、提前破壞使任務物永久失效、讀檔後扳手重試卡關、守衛狀態未保存、JSON數值比較及typed Array問題、負生命破壞物不能讀檔、截圖成功訊息未查寫入結果、操作提示與實際F／Q按鍵不符。修正後的定向檢查與最終重跑均通過。

目前尚未完成：人類全程試玩及時長、多人、手機、原生Linux playable發行、全部三態破損美術、精準騎姿IK、作者LOD／UV1及完整導航避障。第一章Alpha不會結算MAIN-012的完整戰役結局。

繁中文案校對：新增文案按mode2直接套用，已將「結局／獨立／项／後續」改為「結局／獨立／項／後續」，並把錯誤操作提示「E上下車、1–3換工具」改成實際「F上下車、Q換工具」。數值、姓名、ID與授權未因文案校對改動。
