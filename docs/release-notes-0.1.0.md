# 七期：斷鏈行動 Alpha 0.1.0

第一個可玩的開源版本。以台中七期商辦街景為靈感，玩家遭虛構投資平台詐騙後，追查門面、打砸設備、保住紀錄並救出受困者。

下載Windows ZIP，解壓縮後執行SevenDistrict.exe。玩家不需安裝Godot或Blender。

本版包含五個第一章主線、破壞／蒐證／救援三種解法、汽車、自行車、三款器具、守衛與救援、繁中HUD與存讀檔。原始碼、25份Blender源檔、25個GLB、使用到的源模型與素材授權都在公開倉庫。

339項本機檢查通過；Windows封裝執行檔已實際啟動取得畫面。RTX2060、1366×768、Alpha短場景三跑p95中位數17.2ms，並不代表完整MVP或最低配備效能。

操作：WASD移動，Shift衝刺，滑鼠看向，左鍵攻擊，E互動，F上下車，Q換器具，Space跳躍／煞車，R取回載具，Tab任務，Esc暫停，F5/F9存讀檔。

這是開發中的Alpha；完整六區MVP、額外任務、精準騎姿IK、破損網格、交通與長時間人類試玩仍需擴充。Windows執行檔尚未簽章。CI以範本附上，目前未啟用GitHub Actions。
