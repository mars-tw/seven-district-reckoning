# 七期：斷鏈行動｜第七輪視覺規格（repo R10）

這是黃昏台中街坊的查證故事。識別來自有裝訂邊的黑色案卷、證據黃、朱紅圈註、橘包外送員與拿扳手的車店主理人。遊戲前 3 分鐘與商店截圖共用同一套表現。

| 色盤 | HEX | 用途 |
|---|---|---|
| 炭墨 | #16181D | 介面主底、紙上文字、遮罩 |
| 案卷紙 | #F1E8D5 | 證物與書面內容 |
| 證據黃 | #FFB800 | 已選取證據、街區唯一主操作「互動」 |
| 封存朱紅 | #C4271C | 矛盾結論、戶名圈註、封存印 |
| 牛皮 | #9A7443 | 裝訂邊、街景暖灰 |
| 舊帆布包 | #AD7D50 | 阿遠專屬側背包，抑制原本過亮的橘色 |
| 橄欖 | #6D7653 | 美晴工作衫，限定人物服裝 |

UI 只用炭墨、案卷紙、黃、朱紅；服裝的橘與橄欖不挪作狀態色。刪除綠色阿遠名牌與粉紅安全條；唯一條狀訊息明寫「體力 n／100」。距離直接附在任務句尾。

字體沿用 OFL Seven District Sans TC，以實際腳本重建字元子集。標題用粗墨斷鏈 Logo；閱讀順序為主標 28、區塊 19–24、正文 16–18、註解 13，矮橫向至少 13。時間、戶名與金額由程式排字，生成圖的字紋不參與遊戲判定。

面板造型：硬邊紙頁、左側裝訂、壓紋與切角。任務框接入生成的黑案卷表面，保留窄邊、不拉伸成大圓角。按鈕最大 2px 圓角、左邊 3px 裝訂線，黃實心表示主操作，禁用為灰墨。觸控命中至少 44px。案卷採全暗底，穩定保留捲動寬度但不顯示灰色系統捲軸，以紙緣翻閱提示與證物進度引導。返回與繼續固定在可視範圍。

圖示是有材料感的手機、收據與斷鏈，單一物件剪影、深墨邊、少量黃／朱紅。拒用 emoji、空佔位格與泛用科幻圓環。原有三顆街區指令保留可讀短標籤。

人物先依 docs/art/character-sheets/r7-cast-turnaround.png 的正側背面與表情設定；實際 R9 Blender 正側背面在 character-sheets/r9/。阿遠：深靛夾克、黃袖標、白鞋、有翻蓋雙扣與連續背帶的舊帆布側背包。美晴：橄欖衫、鏽紅圍裙、黃抹布、不對稱短髮、手持扳手。左上暖主光、少量冷灰暗面、細深墨輪廓；對話改腰上實心裁切，底緣接不透明對話標頭，取消透明淡出 shader。3D 保留真骨架及原八種動畫；美晴 idle 以真骨架彎肘握工具。仍不宣稱街區模型與繪畫立繪已無精度差距。

街景：細粒柏油與窄騎樓磚兩段，灰黃舊粉牆打散大面積重複磁磚；鐵捲門、停放機車、排水溝、抽屜工作台、工具掛板與單車建立生活密度。黃昏太陽在地平線上，街景與插畫共用暖光方向。生成貼圖只作 diffuse；不虛構 normal／ORM。

證據：甲乙縮圖可以點開全屏，放大後直接呈現可比較的戶名、時間、金額，紅圈只給個人戶名，黃螢光標示留證欄位。連結頁左黃為玩家選取證據、右紅為矛盾結論。封存保留落印、紙面反應與封條貼合的實際補間，另外擷取動作瞬間。

跨款區隔：依 VISUAL_REFRESH_PLAN 唯讀規格比較，兒童交通的明亮教學、末日灰燼、東方神話塔防、華麗卡牌、暖色像素農場與裂隙小隊動作均不採本作的都市案卷／查證攝影語彙；本輪不讀寫其他遊戲資產。

品質：可見人物區 HSV V 平均 0.30–0.75、近黑 <35%、S 均值 ≥0.32、低飽和 <20%。另留 64px 實際人物裁圖；量化不能取代辨識與構圖檢查。生成用共同風格前綴，記錄於 PROMPTS.json round7、round8。透明後處理、授權、PNG／WebP 尺寸、位元組數與雜湊入 manifest；商店證據維持原尺寸、禁止後製合成。

R8 收尾規格：乾淨纖維紙底不含任何圈、格線、孔洞或文字。裝訂孔與紅繩由介面繪在專屬 40px 左邊距，正文、選項與頁腳均避開；證物不使用裝訂裝飾。客服文件採暖灰對話底、客服抬頭、時間與紙白氣泡；轉帳收據採紙白框線、分隔與留存編號。黃線寬度只比實際文字多 18px 內距；唯一紅圈為「林○翔（個人）」。原虛構證物內容不變。

封存有固定印章槽，同一朱紅印文由按壓顯影到完成，不疊木柄遮字；完成頁只留印文與矛盾結果兩層，以及一顆返回街區主按鈕。街區使用真正的天空環境圖與建模屋簷／排水管／電線輪廓，保留 3D 探索。機車烤漆回到低彩度橄欖灰，放大美晴並保留原店外交談位置、紅圍裙與扳手；人物腳下補暖色接觸陰影。

R9：證物紙頁及其連續紙底頁腳涵蓋垂直視口，黑底上下合計不超過高度 10%；返回鈕嵌在頁腳，主文件與返回命中區不重疊。連結頁的欄位名及值是純文字清單，右側獨立 48×44px「比對」分頁才有按鈕外型；原三個選證與錯誤回饋均保留。

沿用 R7 標題 Logo、App 圖提案、手機／收據／斷鏈圖示及角色身份；只新製美晴腰上立繪，阿遠為如實標示的既有圖裁切。R8 天空、屋簷、招牌光及生活物件沿用。R9 工作台保留有厚度的掛鉤與工具，將工具半徑提高以維持實際遊玩距離的輪廓；包袋做布褶、連續背帶及降彩度。家具與人物均有接觸陰影；不為增加素材數量重畫清單外畫面。

R10 固定狀態規則：已選取只用證據黃；已完成用勾選加灰墨或朱紅結果；滑鼠／鍵盤焦點用墨色或紙白外框，未核對的三顆「比對」同色。禁用繼續鍵上方明寫缺少步驟。街區體力條、搖桿中心及進度退為紙灰，唯一黃色操作為有切角、穿孔與紅繩的證據標籤；搖桿用雙層裝訂環與穿孔，目標只留腳圈。五案縮為五格進度點，不再逐格堆待核小字。

R10 地面使用大尺度柏油水漬原畫，僅作 diffuse，保留實際路緣、排水與店基接觸陰影。六件工具為扳手、鉗、起子、套筒與棘輪的立體輪廓，留出間距與掛板陰影；側背包改有側袋、聚褶、弧面翻蓋與受力接點。角色臉、髮型、圍裙與八個真骨架動作沿用設定，不把本輪包袋修整冒充新人物。證物下半部只放同案來源與甲乙核對筆記；引號內字組使用禁止斷行規則，原虛構事實與推論邊界保留。
