# 第七輪人物識別與包袋設定

先沿用既有角色三視圖／表情金標 `r7-cast-turnaround.png` 及實際源模型 `r9/hero_human-front.png`、`hero_human-side.png`、`hero_human-back.png`。本輪不改角色臉、頭身比、衣服或骨架；只重製阿遠的包袋幾何。

正面：保留深靛外送夾克、黃袖標與斜跨連續背帶；背帶連到胯旁包體受力點，不懸空。側面：柔軟舊帆布側袋與聚褶，包體略下垂；側袋可辨、不能是一整塊直角盒。背面：弧面翻蓋、深色扣帶、暗黃銅扣；三面皆使用同一包體與同一材質，不另畫替身。

美晴沿用短髮、紅圍裙、橄欖工作衫、黃抹布與持扳手姿勢。兩人主光皆左上暖光、陰面冷灰；不加新的飽和 UI 色。

製作後從保存的 Blender 源模型以 CPU 背景模式渲染阿遠正／側／背至 `r10/`，不把設定表或棚拍圖當商店實機截圖。每個真骨架八 clip 與原 CC0 來源必須保留。
