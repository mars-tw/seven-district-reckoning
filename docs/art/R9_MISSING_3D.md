# 第六輪邊界與缺件（repo R9）

本輪已實際修整兩名主要人物與工作台，原始 Blender、GLB、八種人物骨架動畫、正側背 QA 及來源雜湊均已保留。沿用的天空、屋簷、招牌與生活物件沒有冒充新增。範圍限於 ART_RESCORE5_MUSE 的五項，不增加系統或場景。

仍為 BLOCKED：

- 獨立美術重評尚未執行，不能自行宣布 8 分以上。美晴的短髮、圍裙、抹布與扳手已加強，但 3D 五官、手指握持、表面細節與 2D 繪畫仍有精度差距。縮圖自審與幾何檢查不等於真人盲測。
- 桌機並發載 p95 ≤18ms 與上一輪歷史退步的唯一根因尚未驗收。現場共享 GPU 在本線瀏覽器關閉時仍為 96% 使用率；沒有停用其他線路、減低截圖解析度或降低原畫質。前後原始跑數、場景面數及限制見 `docs/evidence/r9-art/performance*.json`。不得把手機 CSS 視口的 Web 計時稱為真手機實機。
- 原生 iOS／Android 實機、乾淨機況 GPU timer 及實際 Godot 角色逐物件遮罩的亮度／飽和度閘門仍缺；2D 立繪 alpha 雙閘另有確實量測。native_touch fixture 已通過，不代表原生裝置驗收。

現有遠景、非主角人物及其他工作台未重做，不能宣稱整個街區都已脫離低多邊形風格。後續若獨立複審仍判街區未達標，應以這批實際商店圖指出具體缺口，繼續在既有開場修整；不以新增功能或宣傳插畫充數。
