# 第五輪保留缺件（repo R8）

0.12.0；本輪只收最新 Muse 五項，沒有增加新系統或新畫面。

- 主要人物沿用原 MakeHuman 真骨架；已放大美晴、強化扳手與紅圍裙，未重做臉部拓樸、手指握持或製作修車動畫。64px 裁圖只能確認衣色／輪廓，不能宣稱五官已達近景精度。
- 車店屋簷、管線、輪胎、盆栽為本輪 Blender 新作；遠景建築、部分既有路人、車輛與工具仍是簡化模型。工作台沿用 R7 真實幾何，沒有把貼圖窗景當成新 3D 店內。
- 天空為生成的環境貼圖，映射在實際 3D 世界；不是用生成街景代替玩法。新增 diffuse 不虛構 normal／ORM。
- 阿遠原八種骨架動畫保留；本輪關鍵獎勵回饋是木柄印章落下／抬起及封條貼合的 UI 補間，不冒充新人物攻擊／修車骨架動畫。
- 人物雙閘只重測保留的 2D 立繪 alpha；尚無全街區 3D 人物的逐物件遮罩量測。原生 iPhone／iPad／Android 實機與乾淨機況 GPU p95 尚未驗證。
- 獨立 8 分以上仍待 Muse 重新複審；本機自審、原尺寸截圖和測試不能替代該分數，也不代表 Apple 4.3 已通過。
