- **三張嘴，一句真話**：親訪林秀蘭、陳奕廷、吳安琪。案卷與上方提示同時指向當前受訪者。回到推論頁，以同一條首筆／中間筆／末筆紀錄帶核對說法；依所選文件亮起相關位置。最後逐筆釘上索引，封存仍保留紀錄帶及對應的勾、叉與人物結果。
