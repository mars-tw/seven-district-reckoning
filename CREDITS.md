The bicycle has been modified in Blender for scale, axis alignment, mesh separation, pivots, UV preservation, and seat/hand/exit markers. Attribution to Poly by Google and the license link must remain with redistributed copies; no endorsement is implied.

Kenney models were adapted in Blender for the game's scale, pivots, character rig, palette, animation, and scene assembly. Copies of each source license and retrieval hashes are retained in assets/provenance/. The downloaded source ZIPs are not required to run the game and are not included in the repository; the small set of used source models is included.

The original Noto Sans TC font was retrieved from the upstream repository at commit f8d157532fbfaeda587e826d4cd5b21a49186f7c; its source and retrieval hash remain in [the font ledger](assets/provenance/font-source.json). Alpha 0.2 uses a game-text subset renamed **Seven District Sans TC** (about 171 KiB), retaining the original copyright and OFL license. The full original font is retained as source; Web builds package the subset only. A new game-text change may require rebuilding the subset. This project's code license does not replace the font's OFL or any third-party asset license. See LICENSE-ASSETS.md for the asset license boundaries.
