# Contributing

Seven District is an original, open-source third-person action game built with Godot and Blender. Contributions to code, art, missions, accessibility, tests, and documentation are welcome.

1. Read README.md and the current alpha limitations before changing scope.
2. Use Godot 4.7.2 stable. Keep Blender sources outside godot/ and retain source/export provenance.
3. Keep changes bounded to an existing ticket or clearly stated issue. Do not silently change mission IDs or save schemas.
4. Run the import/parse check and integration checks described in docs/build-from-source.md.
5. Provide reproducible evidence for gameplay, animation, UI, or performance changes. Never label a state-machine test as a full human playtest.
6. Contributed code is MIT. Art must be original or redistributable under a compatible recorded license. Include author, source URL, license text, and modification notes.
7. Do not submit GTA assets, real scam-facility security layouts, personal data, credentials, local save files, or engine caches.

For bugs, include the version, platform, exact steps, and expected/observed behavior. Do not attach saves or logs containing personal information.
